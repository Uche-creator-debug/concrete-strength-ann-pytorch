# Dataset attribution

Data source: **Yeh, I. (1998). Concrete Compressive Strength** [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PK67

Original dataset license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). See [UCI dataset page](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength).

`train-val.csv` (824 records) and `test.csv` (206 records) are the **pre-split version supplied for this project**, derived from the original dataset. The project removes 19 exact duplicate rows from the training portion when running the notebook. No new measurement data were collected.

The CSVs contain eight input variables (cement, slag, fly ash, water, superplasticizer, coarse aggregate, fine aggregate, age) and one output (compressive strength, MPa).
